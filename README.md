# Spotify Web para Linux

Página de distribuição do cliente independente Spotify Web para Linux, com
reprodução em segundo plano, bandeja e controles de mídia no GNOME.

- [Página do projeto](https://mcdalbu.github.io/spotify-web-linux/)
- [Versões e downloads](https://github.com/mcdalbu/spotify-web-linux/releases)

O cliente usa o player web do Spotify. Spotify é uma marca de seus titulares.
