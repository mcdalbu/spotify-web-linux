Spotify Web
para Linux.

O player web do Spotify em uma janela própria. Feche a janela e continue ouvindo, com controles na bandeja e no GNOME.

Baixar RPM v0.1.1 · Fedora 45 · x86_64

Toque em segundo plano

A reprodução continua ao fechar a janela. Use Sair ou Ctrl + Q para encerrar.

Controles no GNOME

Veja a faixa e a capa no painel de mídia. Reproduza, pause ou mude de faixa pelo GNOME ou pela bandeja.

Electron incluído

O RPM vem com o navegador incorporado. A janela e os menus acompanham o tema do sistema.

Instalação no Fedora

Na pasta em que baixou o RPM, execute este comando. Depois, procure Spotify Web no lançador de aplicativos.

sudo dnf install ./spotify-web-electron-0.1.1-1.fc45.x86_64.rpm
